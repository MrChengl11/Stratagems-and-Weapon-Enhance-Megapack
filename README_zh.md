## 功能列表与特性

整合包收录了 6 款经过深度调优的自研模组：

### 1. 🛰️ 轨道激光无限次使用 (Orbital Laser Free)
* **效果**：解除了原版每局仅能使用 3 次的严苛限制，可无限次呼叫。
* **冷却**：冷却时间从原版的 300 秒降低至 **180 秒**，大幅提升实战支援响应速度。

### 2. 💥 380mm 轨道火力网数量翻倍 (Double 380mm Barrage)
* **效果**：在原版相同的轰炸持续时间内，倾泻的 380mm 高爆弹丸数量直接**翻倍**。
* **战术价值**：大幅提高有效覆盖密度，形成末日级的毁灭压制。

### 3. 🚀 双倍荡平者空投 (Double Leveller)
* **效果**：呼叫 EAT-411 荡平者空投舱着陆时，一次性弹出 **2 根** 发射管（原版仅 1 根）。
* **战术价值**：一人呼叫，全队共享，再也不用担心单发打偏。

### 4. 🦅 飞鹰地毯式空袭 (Eagle Carpet Bomb)
* **效果**：借壳“飞鹰 110mm 火箭巢”槽位，完美还原游戏内未正式上线的飞鹰地毯式重型空袭。
* **战术价值**：超宽范围重磅航弹连续投掷，清场神器。

### 5. 🎯 JAR-5 主宰发射爆裂铳弹药 (Dominator - R-36 Eruptor Round)
* **效果**：将主宰的穿甲弹丸替换为 R-36 爆裂铳的强力爆炸破片穿甲弹。
* **战术价值**：赋予主宰超远距离爆炸溅射清杂与拆甲能力。

### 6. 🔫 JAR-5 主宰发射爆弹枪弹药 (Dominator - GP-31 Bolt Pistol Round)
* **效果**：将主宰弹丸替换为 GP-31 爆弹手枪的微型爆炸高射速弹药。
* **战术价值**：高弹容量、高射速与微型爆炸冲击兼备。

> ⚠️ **注意**：主宰爆裂铳与主宰爆弹枪为二选一，请勿在模组管理器中同时勾选。

## 掉帧修复原理与性能架构

在早期版本的 HD2 Lua 注入模组中，许多玩家反馈：**游戏每进行到约 10 分钟、20 分钟时，帧率会突然断崖式减半（例如 60 FPS 跌至 30 FPS），持续 40 秒后自行恢复正常。**

本仓库严格遵循 `hd2-lua-mod` 规范进行重构，从根源上消除了这一问题：

1. **消灭 10 分钟一次的全量重扫风暴**：
   - 原版代码存在 `deep_seconds = 600`，每 10 分钟强制回退到扫描阶段，遍历整个 128TB 地址空间里的近 30,000 个内存区，持续耗尽 2,500 帧（约 40 秒）。
   - 现采用**单向收敛模型**：开局搜索并写入补丁后立即永久休眠，稳态下每 5 秒仅根据已缓存的内存地址做一次微秒级直读校验（开销 < 1μs），绝不再暴力遍历全内存。
2. **硬性 CPU 时间预算 (os.clock deadline)**：
   - 局部维护扫描引入 `local deadline = os.clock() + 0.002`（2ms 硬预算），超预算即刻出让主线程时间，绝不造成主循环单帧卡顿。
3. **安全退钩守卫 (Guarded Update Unhook)**：
   - 采用防截断包装函数，在注销自身钩子时确保下游挂载的其他第三方模组正常运行。
4. **稳态静默运行**：
   - 取消平稳运行状态下每 10~15 秒向磁盘高频写入 `STATUS.txt` 的多余 I/O 操作。

## 安装与使用方法

### 前置要求
* 必须安装 **[Bingus Shared Loader v15+](https://github.com/CowboyBingus/BingusSharedLoader/releases/latest)**。

### 推荐方式：使用 HD2 Mod Manager (HD2MM) 或 Arsenal

1. 从 [`dist/`](dist/) 文件夹或 Releases 页面下载 [**`DSH-Mods-Megapack.zip`**](dist/DSH-Mods-Megapack.zip)。
2. 将 `DSH-Mods-Megapack.zip` 拖入 HD2 Mod Manager 或 Arsenal 窗口进行导入。
3. 打开该 Mod 的 **Options (选项)** 弹窗：
   - **预设 1**：【全套整合】战备全套 + 主宰改爆裂铳
   - **预设 2**：【全套整合】战备全套 + 主宰改爆弹枪
   - **预设 3**：【战备整合】仅战备全套 (不修改武器)
   - 或自由勾选下方的【独立可选】各模组组合。
4. 点击 **Purge**，然后点击 **Deploy**，启动游戏即可。

### 手动安装方式
若不使用模组管理器，可进入 [`dist/`](dist/) 目录下载各个独立的单 Mod ZIP（如 `Orbital-Laser-Free.zip`），解压出 `Addon/9ba626afa44a3aa3.patch_0`，将其重命名为未被占用的 patch 序号（如 `patch_1`），放置到游戏目录下的 `data/` 文件夹中。

## 源码与自主构建

本仓库包含全部未经混淆的 Lua 明文源码及打包工具链：

```
├── src/                          # 6 款模组的完整 Lua 源码
├── tools/                        # .patch_0 归档打包/解析工具
├── dist/                         # 预先编译打包好的全部成品 ZIP
├── build_megapack.py             # 一键构建脚本
└── verify_pack.py                # 归档与源码完整性自动化校验脚本
```

### 重新打包
```bash
python build_megapack.py
```

### 运行校验
```bash
python verify_pack.py
```
